# 💻 Computer Science Study Archive

컴퓨터공학의 핵심 이론과 실습 내용을 깊이 있게 공부하고 기록하는장소입니다. 

## 📂 Directory Structure

이 저장소는 다음과 같은 체계로 분류되어 있습니다.

- 📁 **Data-Structures-Algorithms**
  - 자료구조 및 알고리즘 문제 풀이 및 개념 정리
- 📁 **Operating-Systems**
  - 운영체제 원리, 프로세스/스레드, 메모리 관리 등
- 📁 **Network**
  - 네트워크 계층 구조, TCP/IP, HTTP 프로토콜 등
- 📁 **System-Programming**
  - 리눅스 시스템 프로그래밍 및 커널 구조 학습

## 📌 About This Archive

- **학습 목적**: 이론의 암기를 넘어 구조적 원리를 이해하고 코드로 구현하기 위함
- **작성 원칙**: 
  1. 개념의 정의와 동작 원리를 명확히 기술합니다.
  2. 단순 요약을 넘어 직접 실습하고 검증한 내용을 바탕으로 작성합니다.

## 🛠 Tech Stack & Environment

- **Language**: Python, C, C++ 등
- **OS**: Linux (Rocky Linux / Fedora)
- **Tools**: Git, Markdown
